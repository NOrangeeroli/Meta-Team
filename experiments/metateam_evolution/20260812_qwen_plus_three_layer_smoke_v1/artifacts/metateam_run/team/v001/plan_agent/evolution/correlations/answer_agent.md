We consistently rely on clearly labeled, self-contained handoffs: PlanAgent specifies exact output format, required computation, and protocol constraints; answer_agent executes independently and returns only the canonical FINAL ANSWER line. This pattern eliminates ambiguity in quantitative tasks. Independent verification is a shared strength — both agents treat numerical results as requiring cross-check, not trust. Communication is highly concise: instructions are atomic, expectations are explicit (e.g., 'exactly `FINAL ANSWER: 391`'), and deviations trigger immediate re-handoff. We have validated that omitting context or leaving format open invites inconsistency, whereas strict framing (e.g., quoting the expected string verbatim) yields deterministic outcomes. Future improvements should preserve this 'constrained interface' discipline: every handoff must declare input assumptions, output schema, and acceptance criteria. No ad-hoc interpretation is permitted — if the instruction says 'return exactly X', then only X is acceptable. This reduces retries, avoids normalization mismatches, and aligns with GAIA’s strict grading. The handoff protocol functions as a contract: PlanAgent commits to clarity and completeness; answer_agent commits to fidelity and independence. This mutual accountability underpins reliability across tasks.
